# Where the legal text goes

nidi's privacy policy and terms are written in iubenda and shown on
nidi.life in nidi's own design. iubenda's "direct text embedding" gives the
document as HTML; that HTML is pasted into the files here, and the build
turns each one into a page (privacidad, terminos) with the site's
typography and colours.

## How to copy a document out of iubenda

1. Open the document in iubenda (Privacy Policy, or Terms and Conditions).
2. "Embed" / "Incorporar".
3. Choose **Direct text embedding** (the option whose preview is the whole
   text, not a button or a link).
4. Copy everything in the box.
5. Paste it into the matching file below, replacing what is there.
   Nothing else in the file.

## The files

| File | Document | Language |
|---|---|---|
| `privacy-en.html` | Privacy Policy | English |
| `privacy-es.html` | Política de Privacidad | Spanish |
| `terms-en.html` | Terms and Conditions | English |
| `terms-es.html` | Términos y Condiciones | Spanish (only if it exists) |

If a document does not exist yet in one language, leave that file empty and
the page falls back to the other language's, as the app does today.

The text is iubenda's and is pasted verbatim: not a word is edited here.
When iubenda's text changes, copy it again into the same file.
